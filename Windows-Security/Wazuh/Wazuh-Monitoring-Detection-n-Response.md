SIEM-002 — Wazuh Security Monitoring, Detection & Response
Роль: Junior SOC Analyst
Сценарій
Компанія Asteria Technologies використовує Wazuh для моніторингу Windows endpoints. SOC отримав завдання перевірити можливості системи моніторингу, виявлення підозрілих змін, аналізу вразливостей та реагування на події.

Environment: Wazuh OVA + Windows 10 VM (WIN10-LABS).
Завдання лабораторної

                №	Завдання	Що потрібно дослідити
1	File Integrity Monitoring (FIM)	Налаштувати моніторинг папки, створити, змінити та видалити файли. Знайти alerts, визначити тип змін.

2	SCA	Провести security configuration assessment Windows. Знайти невідповідності та проаналізувати рекомендації.

3	Vulnerability Detection	Перевірити виявлені вразливості програмного забезпечення. Визначити CVE, severity та affected component.

4	Custom Detection Rule	Створити власне правило виявлення на основі контрольованої події Windows.

5	MITRE ATT&CK	Знайти відповідність виявленої активності техніці ATT&CK та дослідити її.

6	Active Response	Налаштувати та протестувати контрольовану автоматичну реакцію на визначену подію.

7	Threat Hunting	Самостійно знайти підозрілі або незвичайні події у зібраних даних. Сформувати гіпотезу та перевірити її.

Порядок виконання
Не всі конфігурації виконуються одночасно. Частина завдань потребуватиме зміни конфігурації агента або Wazuh Server. Виконуємо послідовно.
- [ ] Stage 1: FIM — моніторинг змін файлів
- [ ] Stage 2: SCA — аудит конфігурації
- [ ] Stage 3: Vulnerability Detection — пошук CVE
- [ ] Stage 4: Custom Rule — власне виявлення
- [ ] Stage 5: MITRE ATT&CK — класифікація
- [ ] Stage 6: Active Response — автоматична реакція
- [ ] Stage 7: Threat Hunting — самостійне розслідування
Умови виконання
- Працюємо на власному лабораторному середовищі.
- Зміни та підозрілі дії генеруємо контрольовано.
- Не видаю наперед результати дослідження.
- Даю мінімальні підказки, якщо застрягнеш.
- Фіксуємо результати, скриншоти та висновки для GitHub-портфоліо.
Критерії завершення
- [ ] FIM виявляє зміни файлів.
- [ ] SCA проведено, результати проаналізовано.
- [ ] Вразливості знайдено та оцінено.
- [ ] Custom rule створено та протестовано.
- [ ] Alert зіставлено з MITRE ATT&CK.
- [ ] Active Response протестовано.
- [ ] Проведено власне Threat Hunting.
- [ ] Сформовано звіт лабораторної.
